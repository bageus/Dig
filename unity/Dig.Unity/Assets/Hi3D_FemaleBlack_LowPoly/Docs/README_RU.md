# Hi3D Female Black — Low-Poly Rigged Animated Unity Package

Исходная модель оптимизирована с сохранением:
- Generic-скелета (36 костей);
- skin weights, до 4 костей на вершину;
- UV и встроенной текстуры;
- всех 14 анимаций;
- attachment sockets и исходной иерархии узлов.

## Варианты

- **LOD0 Balanced** — основной визуал персонажа, около 89,311 треугольников.
- **LOD1 Performance** — для дальних персонажей или большого количества гномов, около 54,516 треугольников.

Исходная модель: 1,999,748 треугольников.

## Unity

1. Скопировать `Assets/Hi3D_FemaleBlack_LowPoly` в Unity-проект.
2. Импортировать через UnityGLTF.
3. Использовать `Mecanim / Generic`.
4. Выключить `Apply Root Motion`.
5. Для LODGroup назначить LOD0 Balanced первым уровнем, LOD1 Performance вторым.
6. Проверить деформации плеч, локтей, таза, коленей, кистей и волос в Play Mode.

## Анимации

Idle, Walk, Run, Climb, Carry, Mine, Chop, Build, Eat, Study, Rest, Attack, Hit, Death

Оптимизация выполнена автоматически методом пространственной кластеризации вершин. Она существенно уменьшает геометрию, но финальную художественную проверку силуэта, UV и деформаций нужно выполнить в Unity/Blender.
