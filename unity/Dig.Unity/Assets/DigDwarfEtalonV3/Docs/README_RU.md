# Эталонный мужской гном V3

Это реальная 3D-модель, а не концепт-изображение.

- без молотка и других предметов;
- выраженные гномьи пропорции: длинный корпус, короткие ноги, массивные плечи и увеличенные предплечья;
- Generic skeleton;
- веса;
- 11 анимаций;
- плоская подошва ботинок;
- четыре PNG-превью отрисованы из самой модели: front/right/left/back.

Импортируйте `dwarf_male_etalon_v3.gltf` вместе с соседним `.bin` через glTF importer. Root Motion должен оставаться выключенным.
